# ADR 0256: Passport Storage V1 Migration Fixture

## Status

Accepted

## Context

ADR 0008 introduced a Rust-native encrypted PinTAN passport format with a
versioned JSON envelope. ADR 0251 reviewed the current KDF, AEAD, and envelope
validation policy.

The v1 release checklist still requires a persisted-format migration test before
the first storage format revision. Existing tests cover roundtrips, metadata,
wrong passphrases, and malformed envelopes, but a roundtrip generated by the
current code does not prove that previously written version-1 bytes keep loading
after a future change.

## Decision

Check in a static encrypted version-1 PinTAN passport envelope under
`tests/fixtures/passport/`.

The fixture:

- uses only dummy values and no real bank credentials;
- uses the current v1 envelope shape and KDF/AEAD metadata;
- is loaded by a dedicated test with a documented dummy passphrase;
- pins compatibility for reading persisted v1 bytes before any future envelope
  version is introduced.

Do not add a public fixture-generation tool for v1. The fixture is release
evidence, not application API.

## Consequences

Future storage changes must keep the v1 fixture loading or add an explicit
migration path before changing the persisted envelope version.

The release checklist can mark the persisted-format migration-test item as
covered for the current v1 format.

Because the fixture is encrypted and contains only dummy data, it can stay in
the repository without credential-handling concerns.
